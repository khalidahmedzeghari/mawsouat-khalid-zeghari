# موسوعة خالد أحمد الزغاري

موقع أكاديمي متعدد اللغات (العربية والفرنسية والإنجليزية) منشور عبر GitHub Pages.

## البنية
- `index.html`: الواجهة العامة، والسيرة المعتمدة، وفهرس المنشورات.
- `admin.html`: لوحة الإدارة الخاصة المتصلة بـ Supabase Auth وRLS.
- `sitemap.xml` و`robots.txt`: ملفات الفهرسة لمحركات البحث.

## البيانات
تُقرأ المنشورات المنشورة ومصادرها من جداول Supabase العامة باستخدام مفتاح Publishable مخصص للواجهة. لا تضع مطلقًا مفتاح `service_role` أو أي مفتاح سري في ملفات الموقع.

## النشر
يُنشر الموقع من فرع `main` عبر GitHub Pages. بعد كل تعديل، تحقّق من الموقع المنشور ومن وحدة تحكم المتصفح.
